The short version

What is an MCP server?

Model Context Protocol (MCP) is a way for an AI assistant to use tools outside its own chat. Kelvin is the course tool: your assistant can request a course map, search for a topic, and read the matching material before it answers.

1

You ask in your chat

Ask a normal ME 300 question. Name Kelvin if your assistant does not select it automatically.

2

Kelvin supplies context

It offers topic and misconception cards, teaching skills, and files your instructor has added for your course.

3

Your assistant responds

The assistant uses that material to guide you. Kelvin also has a question-first tutoring tool backed by the GB10's model.

What gets recorded? Kelvin logs requests and MCP tool activity for service health and course trends. It does not receive your whole chat transcript through MCP. Learning reflections are saved when you explicitly ask. The pilot asks for a PSU email but does not verify ownership yet.

Get connected

Choose your chat app

Use the same Kelvin address in each app. Connection menus and plan support differ, so follow the guide for yours.

Kelvin MCP address

Copy the full URL, including /mcp.

https://kelvin.me.psu.edu/mcp
ClaudeFree, Pro, Max, Ultra, Team, EnterpriseSteps
  1. Open Customize → Connectors and choose Add custom connector. On some accounts this is under Plugins.
  2. Name it Kelvin and enter the URL above.
  3. Continue with the detected sign-in settings. On Kelvin's page, enter your PSU email and choose your professor's course.
  4. Enable Kelvin in your conversation and try the sample question above.

Claude Free allows one custom connector. Claude's connector guide

ChatGPTBusiness and Enterprise/Edu; Pro has limited read accessSteps
  1. Check that your plan or workspace allows custom MCP connections. ChatGPT Free does not currently offer direct custom MCP setup.
  2. On ChatGPT web, open Plugins → Add custom MCP server and enter the URL above. Your workspace admin may need to approve it.
  3. Choose OAuth sign-in, review the tools and permissions, and create the connection.
  4. In a new chat, select Kelvin with @ and ask a thermodynamics question.

Pro connections are limited to read/fetch tools, so some Kelvin features may be unavailable. ChatGPT's MCP guide

GeminiPersonal Google account; US, 18+, English, Keep Activity onSteps
  1. On a computer, open Settings → Connected Apps. If needed, open Personal Intelligence → Connected Apps.
  2. Under Custom apps, choose Add a custom app and enter the URL above.
  3. Continue through sign-in. On Kelvin's page, enter your PSU email and choose your professor's course.
  4. In chat, type @ and select Kelvin.

This feature does not support school Google accounts. Gemini's custom app guide

Another MCP clientRemote HTTPS MCP and OAuth requiredSteps
  1. Find the option to add a remote MCP server.
  2. Paste the URL above as the server address.
  3. Allow OAuth sign-in and choose your course on Kelvin's page.
  4. Enable Kelvin's tools and ask the client to use Kelvin for an ME 300 topic.
